## 형식

- 한 장소를 3D 단면 디오라마로 보여 준다. 땅의 단면이 화면 아래에 보인다.
- 새로 추가되는 것을 강조색으로 보여 준다.
- "근데(문제) → 그래서(해결)"를 5~10초 단위로 반복한다.
- 치수, 화살표, X표, 수치 라벨을 화면에 붙인다.
- 자막은 화면 높이 3/4 지점의 작은 흰색 한 줄이다.
- 질문으로 끝난다.

## 측정 방법

- 프레임과 자막: 페이지 안에서 mp4를 blob으로 `video`에 넣고 `currentTime` 시크와 canvas `drawImage`로 0.1초 간격 측정.
- 자막 전환: 화면 높이 73.5~77.5% 띠에서 RGB가 모두 235를 넘는 픽셀 마스크의 변화량.
- 소리: 자기상관 F0와 스펙트로그램.

`hyperframes reverse start`는 ffprobe가 없어 실행되지 않았다. 위 값은 같은 항목을 브라우저에서 직접 잰 것이다.

# script.json 事实出处对照

- 依据：`research/facts.md`（核实日期 2026-11-25）
- 只列含事实（方法名、人名、数字、研究结果）的句子。举例句（c46）、过渡句、号召句不含事实，不列。
- 选用的 5 个习惯：A 番茄（c13–c21）、B 2 分钟（c22–c27）、C 重要/紧急（c28–c35）、D 时间块（c36–c43）、F 如果–那么（c44–c53，作为“마지막 습관”）。D 与 F 的区别在 c47–c49 讲明（D 给事情定时间，F 定开始的触发信号）。

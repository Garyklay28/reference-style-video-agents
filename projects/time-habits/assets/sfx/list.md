# time-habits 音效清单

全部为 48kHz / 单声道 / 16-bit PCM wav，由 `synth.js` 在浏览器里用 `OfflineAudioContext` 合成。
噪声用固定种子的 mulberry32 伪随机数（不用 `Math.random`），同一浏览器重复运行两次得到的文件逐字节相同（FNV-1a 哈希一致）。
长度和峰值是保存后重新 `fetch` + `decodeAudioData` 实测的数值（2026-11-25，Chromium 内置浏览器）。

| 文件 | 用途 | 长度 | 峰值 | RMS | FNV-1a |
|---|---|---|---|---|---|
| `pop.wav` | 元素弹出（图标、标签、气泡）短促轻柔的“噗”：620→230Hz 下滑正弦 + 2ms 带通噪声起音 | 0.135 秒（6492 采样） | -6.00 dBFS（0.5012） | -19.9 dBFS | 87119373 |
| `whoosh.wav` | 画面切换的轻微“唰”：带通噪声，中心频率 350→2200→700Hz，包络先升后降 | 0.336 秒（16125 采样） | -6.00 dBFS（0.5012） | -22.1 dBFS | df06d56a |
| `ding.wav` | 编号牌出现的清脆“叮”：1320Hz 基频 + 2.0/2.76/5.4 倍泛音，3ms 起音、指数衰减 | 0.545 秒（26137 采样） | -6.00 dBFS（0.5012） | -20.3 dBFS | f5e5a66e |
| `pencil.wav` | 写字或画线的沙沙声：1.8kHz 高通 + 4.2kHz 带通噪声，5 段不规则笔划包络 | 0.495 秒（23752 采样） | -6.00 dBFS（0.5012） | -20.5 dBFS | f7d01311 |

- 前后静音：已裁掉低于峰值 -60dB 的首尾部分，末尾 3ms 淡出到 0。实测首采样绝对值 ≤ 0.001，末采样 = 0。
- 来源：本项目 Web Audio 合成（`assets/sfx/synth.js`），未下载任何外部音效。
- 授权：自制，无第三方版权，无署名义务。
- 重新生成：在 `http://localhost:4801/` 下的同源页面加载 `synth.js` 后运行 `await SFXSynth.run({ save: true })`，再用 `await SFXSynth.measure()` 实测。
- 未确认：没有亲耳试听，音色是否合适需要人确认。
